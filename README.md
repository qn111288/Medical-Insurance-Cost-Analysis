Medical Insurance Portfolio AnalysisA data-first approach to health insurance portfolio analysis: Deep Analysis -> Feature Engineering -> Modeling.  Dataset OverviewSize: The main dataset contains 228,711 rows and 42 columns, with a memory usage of approximately 184.11 MB.  Target Variable: premium (Regression task).  Data Characteristics: The distribution of the premium variable is right-skewed (Skewness: 4.843). Several columns have a very high percentage of missing values, such as date_lapse_policy and year_lapse_policy missing 76.33% of their data.  Quick Start GuideThe project is configured to automatically detect the execution environment (Kaggle, Google Colab, or Local) and adjust data paths and output directories accordingly.  Running on KaggleAdd Data: Click "Add Data" and search for the "health insurance portfolio" dataset, or upload the Excel file.  Enable GPU (Recommended): Go to Settings on the right side, and under "Accelerator" select "GPU T4 x2" or "GPU P100".  Execute: Click "Run All" to execute all cells.  Results: All plots will be saved to the /kaggle/working/plots/ directory.  Running LocallyEnsure the dataset is placed in the data/Dataset of health insurance portfolio/ folder.  Use Python 3.8+ with the required packages installed and select a Python 3.13 kernel.  Click "Run All" to execute the code.  Environment & LibrariesThe notebook automatically checks for and installs missing packages. Core libraries used include:  Data Analysis & Processing: pandas, numpy, openpyxl.  Visualization: matplotlib, seaborn.  Modeling (GPU Supported): scikit-learn, xgboost, lightgbm, catboost. These models automatically use GPU acceleration if available to speed up training.  Additional Tools: imbalanced-learn, shap.  Main Project PhasesPhase 1 - Data Loading & Initial Understanding: The script automatically searches for the main Excel dataset file while skipping metadata/descriptive files. It also analyzes the columns to automatically identify the target variable.  Phase 2 - Comprehensive Exploratory Data Analysis (EDA):Descriptive Statistics: Extracts statistics for 27 numerical features.  Missing Values Analysis: Summarizes and visualizes (via Heatmap) columns with more than 5% missing data.  Target Variable Analysis: Generates Histograms and Box Plots to investigate the distribution and skewness of the premium variable.  Correlation Analysis: Builds a Pearson Correlation Matrix to find highly correlated feature pairs (|r| > 0.8), for instance, year_effect_insured and year_effect_policy which have a correlation of 0.960.
